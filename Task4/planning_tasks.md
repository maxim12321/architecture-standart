# Список крупных задач для будущего планирования

Список разбит по системам, в которых задачи должны быть реализованы.

## Internet-bank system

1. Интеграция с API Deposit Request system для отправки заявок в
   очередь
2. Доработка интернет-банка для отображения ставок и приема заявок
   на депозит

## Website

1. Доработка сайта для приема заявок на депозит

## Deposit Request system

1. Развертывание основных компонентов: API, очередь сообщений, сервис,
   БД
2. Разработка API для интеграции других сервисов с Kafka
3. Обработка сообщений из Kafka в сервисе с сохранением в БД
4. Интеграция с АБС для сохранения подтвержденных заявок
5. Интеграция с очередью сообщений системы нотификаций
6. Отправка СМС-сообщений через очередь сообщений системы нотификаций

## Call-center system

1. Доработка системы кол-центра для отправки заявок через API Deposit
   request system

## Notification system

1. Развертывание основных компонентов: очередь сообщений, сервис
2. Обработка событий из очереди в сервисе нотификаций
3. Интеграция со шлюзом телеком-оператора

## Loan Rates system

1. Развертывание основных компонентов: веб-клиент, веб-сервер, БД
2. Добавление возможности указания общих ставок для сотрудников отдела
   кредитования
3. Добавление возможности указания персонализированных ставок
4. Интеграция с кол-центрами через протокол SFTP
5. Экспорт актуальных ставок в файловом виде для кол-центров
